# AI Strategy Optimizer

A Python-based AI simulation for optimizing Prisoner's Dilemma strategies using Hill Climbing, Genetic Algorithm, and Simulated Annealing.

[View the project report](https://drive.google.com/file/d/18I5AwPR5vF34i2ZaWZGbcDzBySgKURPg/view?usp=sharing)

## Overview

This project compares three optimization algorithms on repeated Prisoner's Dilemma strategies. Each algorithm searches for strategy parameters that improve performance against different opponent behaviours, including Always Cooperate, Always Defect, and Tit-for-Tat.

The goal was to evaluate how different AI optimization methods perform in a strategic decision-making environment.

## Algorithms Used

- Hill Climbing
- Genetic Algorithm
- Simulated Annealing

## Opponent Strategies

- Always Cooperate
- Always Defect
- Tit-for-Tat

## Key Features

- Simulates repeated Prisoner's Dilemma matches
- Tests strategy performance across multiple opponents
- Compares optimization algorithms using repeated trials
- Evaluates algorithm effectiveness based on final strategy scores

## Results Summary

The project tested how well each optimization method improved strategy performance over repeated simulations.

- Hill Climbing produced strong results through local search.
- Genetic Algorithm explored a wider solution space using population-based optimization.
- Simulated Annealing balanced exploration and exploitation by allowing occasional worse moves.

Full methodology, testing process, and results are available in the project report.
